## 🕹 Game Description
A project with a UI simulation of the process of writing files to a disс with elements of an arcade mini-game like Xonix.

## 🧠 The Goal of the Game
Burn as many files as possible to a disk, effectively using its limited space, while increasing file compression through an arcade mini-game.

To fit the files onto the disc, the player can go through compression levels. The better he does in the mini-game, the more the file is compressed, and the more files can be written.

## 🎮 Mini-game
- The player controls the square by cutting off parts of the field.
- The center of the playing field is protected by an enemy firing projectiles.
- The goal is to cut off a given percentage of the field without losing all lives.

## 📦 Installation and Launch
1. Clone the repository:
   ```bash
   git clone https://github.com/protsenkovlad25/CDArchive.git
   ```
2. Open the project in Unity (version 6000.0.34f1 or higher).
3. Launch the SampleScene via Assets/Scenes.
4. Press ▶ to start.

## ⚙️ Dependencies
- Unity 6000.0.34f1 LTS
- TextMeshPro
- DOTween
- Alchemy
- AYellowpaper.SerializedDictionary
- NewtonsoftJSON

## 🔨 Build Instructions
1. Go to **File → Build Settings**
2. Select the **PC** platform
3. Click **Build**
4. Choose the build save location
5. The build is ready
